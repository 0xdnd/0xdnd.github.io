ZeroBox (ctftracker.com)

Free offline CTF tracker for HackTheBox & TryHackMe — OSCP/CPTS/CRTO exam simulator, writeups and cheatsheets.

Problem

Progress across 1,000+ HTB and TryHackMe machines was scattered, there was no timed, realistic exam practice, and ports, reverse shells and evidence notes were copied manually during recon.

What I Built

An offline-first workspace in React and TypeScript, shipped as a web app and a Tauri desktop app: a catalog of 1,000+ machines, 131 reverse shell templates, an 8-step methodology, multi-host Nmap XML import with one-click attack graphs, a masked vault for credentials and hashes, a Markdown report generator scored by CVSS v3.1, and a timed exam simulator (OSCP, CRTO, OSEP, CRTP and more) with ZIP submission export.

Result

14,000+ unique visitors and 30,000+ pageviews in the first 39 days at ctftracker.com — from 95 visitors on launch day (Oct 7) to a peak of 1,200+ on Nov 4, now holding at 400–800 most days. Open source on GitHub (0xdnd/ctf-tracker): 45 stars, 4 forks, 8 releases — latest ZeroBox v2.5.5. Runs fully offline, with no accounts and no cloud telemetry; data stays in the browser (IndexedDB / LocalStorage).
