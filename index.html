ZeroBox (ctftracker.com)

CTF tracker and penetration testing workspace.

  • Problem

    Progress across 1,000+ HTB and TryHackMe machines was scattered, there was no realistic timed exam practice, and ports, reverse shells and evidence notes were copied around by hand during recon.

  • What I built

    An offline-first workspace in React and TypeScript, shipped as a web app and a Tauri desktop app: a 1,000+ machine catalog, 131 reverse shell templates, an 8-phase methodology, a multi-host Nmap XML importer with one-click attack graphs, a masked credential and hash vault, a CVSS v3.1 Markdown report generator, and a timed exam simulator (OSCP, CRTO, OSEP, CRTP and more) with ZIP submission export.

  • Result

    4,000+ visitors at ctftracker.com, open source on GitHub (0xdnd/ctf-tracker). Runs fully offline with no accounts and no cloud telemetry; data stays in the browser (IndexedDB / LocalStorage).
